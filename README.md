# Amin Test
اپ آمادگی آزمون استخدامی (Capacitor + HTML/JS).

## ساخت APK با GitHub
1. یک مخزن جدید در GitHub بساز و همهٔ فایل‌های این پوشه را (با `.github`) در شاخه main آپلود کن.
2. تب Actions → «Build APK» (به‌صورت خودکار با push اجرا می‌شود، یا Run workflow).
3. بعد از پایان، از پایین صفحهٔ run در بخش Artifacts فایل `Amin-Test-APK` را دانلود و unzip کن؛ داخلش `app-debug.apk` است.

## تکمیل پاسخ‌ها
پاسخ‌های تکمیلی در `www/answers_extra.json` به شکل `"Q000003": 3` (عدد ۰ تا ۳ = گزینه ۱ تا ۴) هستند.
